# CatOpt

CatOpt est un projet d'optimisation de programmes à l'aide de lois algébriques et de la théorie des catégories.

Le projet est en cours de développement et **n'est pas encore utilisable comme optimiseur de code source** : il ne dispose pas de lexer (analyseur lexical) ni de parser (analyseur syntaxique). Les programmes sont actuellement construits directement en C++ à partir des types du projet, puis interprétés et optimisés.

La théorie et un exemple détaillé de la première version sont présentés dans **[catopt.pdf](latex/catopt.pdf)**.
